# Federation Lab v0.1.0

The first stable snapshot of the educational TanStack Start + Module Federation +
Rsbuild reference, following v0.1.0-rc.1. This is a GitHub source release, not an
npm package. It uses the published `@module-federation/tanstack@0.4.0` in all four apps.

- Remote manifest diagnostics in `/lab` show structured failure codes, HTTP status
  and retry guidance, with recovery after a remote restarts.
- 26 new public-API checks cover network errors, timeouts and their original cause,
  HTTP retry classification, bounded body previews, JSON parsing, response-size
  limits and CommonJS SSR entry fetch/evaluation failures.
- Request activity panels correlate catalog operations and SSR requests with
  backend responses. React behavior tests cover hydration, filtering, retries and
  stale response handling; PR reports compare coverage with the exact base commit.
- SSR preloading preserves visible inline remote content on first requests and
  after outages, including with JavaScript disabled. Private remote server
  functions, generated type contracts and session isolation remain covered.
- Updated development dependencies and Node minima: 22.22.2+, 24.15.0+, or 26+,
  as specified by `package.json`.

See [the 0.4.0 applicability and test matrix](../../TESTING.md#module-federation-tanstack-040)
for the tested Rsbuild paths and the excluded Vite-specific loader path.

## Run this release

```sh
git clone --branch v0.1.0 https://github.com/mes113/tanstack-start-federation-lab.git
cd tanstack-start-federation-lab
npm ci
npm run build
npm run dev
```

Open http://127.0.0.1:3005/guide. For tests, stop dev, install Chromium with
`npx playwright install chromium`, then follow [TESTING.md](../../TESTING.md).

Demo identities and in-memory notes remain teaching fixtures. This source release
does not provide production authentication, persistent storage or deployment automation.
