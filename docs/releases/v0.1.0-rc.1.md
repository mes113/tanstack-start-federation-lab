# Federation Lab v0.1.0-rc.1

First release candidate for the interactive TanStack Start + Module Federation +
Rsbuild reference. This tag is a reproducible Git snapshot, not an npm package.

- MIT license for original code; upstream and shadcn notices are retained.
- Guided catalog, session and resilience experiments with expected results,
  labelled page-loader snapshots, live remote responses and linked code.
- Shared React-only shadcn/ui primitives across all four applications, including
  standalone remotes; inactive handbook tabs preserve the mounted example.
- `npm run doctor` and automatic startup preflight for Node, dependencies,
  required ports, production entry points and the Playwright browser.
- Published `@module-federation/tanstack@0.2.0`, component-owned private server
  functions, generated remote declarations, full SSR and failure/recovery demos.
- Rstest unit, native federation/SSR and production/development browser suites,
  with required CI, coverage reports and updating PR coverage comments.

Use the README quickstart on this tag. Install Chromium with
`npx playwright install chromium` before browser tests. Test commands own their
fixture processes; stop the dev demo before running the browser suites.

Demo identities and signing keys are local fixtures. Notes are held in memory.
This candidate is an educational reference, not production identity management
or a production deployment template. Unit coverage does not measure the separate
browser/SSR/backend processes used by integration tests.
